# Stylophorum-IPMs

Scripts for the integral projection model and integrated population
 model for the wood-poppy
 
#-----Scripts-----------------------------------#

Wood_Poppy_IProj_M

* Script for the integral projection model for each of the four
  wood-poppy populations that could be modelled
  
* Includes analyses of the model: elasticities and simulations

Wood_Poppy_IPopM

* Script for the integrated population model for each of the five
  wood-poppy populations that could be modelled

#-----Data Files-------------------------------------------#

##-----Integral Projection Model-----##

SurvData_IProjM

*Survival, growth, and flowering data for wood-poppy plants 2022-2025

##-----Integrated Population Model-----##

Wood_Poppy_All

* Wide format of wood-poppy measurements of individuals

Wood_Poppy_Vertical

* Long format of wood-poppy measurements of individuals

WSP_Data_Clean

* measurements of individual plants 2020-2021

Untagged_Data

* Number of individuals counted but not tagged at each population

Count_Data

* Counts of individual plants in each population in each year

MarkRecapture_Multistate

* Multi-state (i.e. age-based) mark-recapture data for the tagged individuals
